# Bleval AI OS — Glossary

- **Executive** — Autonomous agent that manages an organization's strategy and departments
- **Learning Engine** — Continuous monitoring system that scores executions and detects patterns
- **Pattern** — A detected trend (error, bottleneck, performance, learning) derived from analytics
- **Recommendation** — A suggested improvement generated from a pattern
- **Knowledge Entry** — Consolidated learning promoted to memory
- **Playbook Evolution** — A recorded change to an agent or workflow playbook
- **Score History** — Running performance scores across workflow/executive/agent entities
- **Learning Cycle** — Full measure → learn → improve loop
