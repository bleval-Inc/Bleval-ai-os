# Bleval AI OS — Global Glossary

## Core Terms
- **Organization**: A distinct business entity with its own executives, departments, agents, tools, and memory
- **Executive**: C-suite AI agent responsible for an organization's strategy and operations
- **Department**: Functional unit within an organization with specific KPIs and playbooks
- **Agent**: Individual AI worker with defined capabilities and responsibilities
- **Capability**: A discrete, searchable skill that an agent exposes
- **Workflow**: A defined sequence of steps coordinating multiple agents toward a goal
- **Event**: A signal that something important happened; agents subscribe to events
- **Tool**: An external service or system abstracted behind an interface
- **Runtime**: The AI execution engine (replaceable, currently Ruflo)
