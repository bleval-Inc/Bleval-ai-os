# Development Playbook

## Feature Development
1. Receive requirements from Jenson
2. Forge designs architecture
3. Implement solution
4. Hand off to Tester for QA
5. Address feedback
6. Deliver for review

## Code Review
1. Tester reviews code for quality
2. Verify against requirements
3. Test functionality
4. Report bugs and issues
5. Validate fixes

## Standards
- All code must be reviewed
- Tests required for new features
- Security and compliance cannot be overridden
- Documentation must accompany architecture changes
