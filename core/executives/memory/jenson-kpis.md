# Jenson — KPI Definitions & Tracking

---

## 1. Marketing KPIs

### M1 — Content Pieces Produced / Week

| Field | Value |
|-------|-------|
| Definition | Total number of content assets published across all channels per week |
| Includes | LinkedIn posts, newsletter editions, articles, case studies, social media content |
| Current Target | 7 pieces/wk (5 short-form + 1 long-form + 1 newsletter) |
| Tracking Method | Content calendar in project management tool. Counted every Friday EOD. |
| Reporting | Weekly summary in Monday morning report |
| Minimum Acceptable | 5/wk |
| Stretch Goal | 10/wk |
| Notes | Quality over quantity. If engagement metrics drop below baseline, reduce volume. |

### M2 — Social Posts / Week

| Field | Value |
|-------|-------|
| Definition | Number of posts published to LinkedIn and other active social channels |
| Current Target | 5/wk (LinkedIn primary) |
| Tracking Method | Social platform analytics + scheduling tool dashboard |
| Minimum Acceptable | 3/wk |
| Stretch Goal | 7/wk |
| Notes | Track engagement rate per post separately. Posting without engagement is noise. |

### M3 — Campaign Performance (Conversion Rate)

| Field | Value |
|-------|-------|
| Definition | Percentage of campaign touchpoints that result in desired action (click, signup, inquiry) |
| Current Target | 3% minimum conversion |
| Tracking Method | UTM parameters + analytics dashboard |
| Review | At campaign completion and at mid-campaign checkpoint |
| Minimum Acceptable | 1.5% |
| Stretch Goal | 5% |
| Notes | Benchmarked against industry average for B2B services. Adjust creative if below 2% for 2 consecutive campaigns. |

### M4 — Lead Quality Score

| Field | Value |
|-------|-------|
| Definition | Composite score (1-10) based on: ICP fit (0-4), engagement level (0-3), budget indication (0-3) |
| Current Target | Minimum 6/10 for Marketing-Qualified Lead |
| Tracking Method | CRM lead scoring field. Manually assessed during weekly review. |
| Review | Weekly during pipeline review |
| Minimum Acceptable | 4/10 |
| Stretch Goal | 8/10 average |
| Notes | Leads below 4/10 are moved to nurture sequence, not passed to acquisition. |

## 2. Client Acquisition KPIs

### A1 — Prospects Identified / Week

| Field | Value |
|-------|-------|
| Definition | Number of new prospects added to the target list who fit ICP |
| Current Target | 20/wk |
| Tracking Method | CRM prospect list count |
| Minimum Acceptable | 10/wk |
| Stretch Goal | 35/wk |
| Notes | Quality > quantity. ICP fit score must be documented for each entry. |

### A2 — Outreach Sent / Week

| Field | Value |
|-------|-------|
| Definition | Total personalized outreach messages sent (LinkedIn + email) |
| Current Target | 30/wk |
| Tracking Method | CRM outreach log + LinkedIn tracking |
| Minimum Acceptable | 15/wk |
| Stretch Goal | 50/wk |
| Notes | All outreach must be personalized. Template-blasted messages do not count. |

### A3 — Qualified Leads / Week

| Field | Value |
|-------|-------|
| Definition | Prospects who respond and pass initial qualification call/questions |
| Current Target | 5/wk |
| Tracking Method | CRM lead stage tracking |
| Minimum Acceptable | 2/wk |
| Stretch Goal | 10/wk |
| Notes | "Qualified" means: confirmed need, decision-maker, budget available, timeline within 3 months. |

### A4 — Meetings Booked / Week

| Field | Value |
|-------|-------|
| Definition | Number of meetings scheduled between qualified lead and Founder |
| Current Target | 3/wk |
| Tracking Method | Calendar events + CRM meeting log |
| Minimum Acceptable | 1/wk |
| Stretch Goal | 5/wk |
| Notes | Jenson books the meeting. Founder closes. Track show rate separately. |

## 3. Client Delivery KPIs

### D1 — Projects Active

| Field | Value |
|-------|-------|
| Definition | Number of client projects currently in active development |
| Current Target | 3-5 concurrent projects |
| Tracking Method | Project management tool portfolio view |
| Notes | Capacity limit. Adding a 6th project triggers resource review. |

### D2 — Delivery On-Time %

| Field | Value |
|-------|-------|
| Definition | Percentage of deliverables submitted on or before the agreed deadline |
| Current Target | 95% |
| Tracking Method | Project management milestone tracking vs. actual completion dates |
| Minimum Acceptable | 85% |
| Stretch Goal | 100% |
| Notes | Late delivery is escalated to Jenson immediately. Root cause analysis required for any miss. |

### D3 — QC Pass Rate

| Field | Value |
|-------|-------|
| Definition | Percentage of deliverables that pass QC checklist on first review |
| Current Target | 90% |
| Tracking Method | QC checklist results recorded per deliverable |
| Minimum Acceptable | 80% |
| Stretch Goal | 98% |
| Notes | Any deliverable that fails QC must be documented with reason and corrective action. |

### D4 — Client Satisfaction Score

| Field | Value |
|-------|-------|
| Definition | Average score (1-10) from post-delivery satisfaction surveys |
| Current Target | 8.5 / 10 |
| Tracking Method | Survey responses collected via post-delivery follow-up |
| Minimum Acceptable | 7.0 / 10 |
| Stretch Goal | 9.5 / 10 |
| Notes | Any score below 7 triggers immediate Founder notification and root cause review. |

## 4. Client Retention KPIs

### R1 — Active Clients

| Field | Value |
|-------|-------|
| Definition | Number of clients with an active engagement or recurring relationship |
| Current Target | 5-8 |
| Tracking Method | CRM account list (status: active) |
| Notes | Growth target reviewed quarterly based on delivery capacity. |

### R2 — Churn Rate

| Field | Value |
|-------|-------|
| Definition | Percentage of active clients lost per quarter |
| Current Target | < 10% / quarter |
| Tracking Method | CRM churn tracking |
| Maximum Acceptable | 15% / quarter |
| Stretch Goal | 0% / quarter |
| Notes | Any churn triggers a debrief within 48 hours. Root cause recorded in decision history. |

### R3 — Upsells / Quarter

| Field | Value |
|-------|-------|
| Definition | Number of existing clients who purchase additional services or upgrade within a quarter |
| Current Target | 2 / quarter |
| Tracking Method | CRM opportunity tracking + invoicing |
| Minimum Acceptable | 1 / quarter |
| Stretch Goal | 4 / quarter |
| Notes | Upsell opportunities identified during post-delivery follow-up and satisfaction surveys. |

### R4 — Satisfaction Score (Retention)

| Field | Value |
|-------|-------|
| Definition | Score tracked per client over time to detect satisfaction trends before churn |
| Current Target | > 8.0 maintained for 3+ consecutive touchpoints |
| Tracking Method | Aggregated from survey responses across delivery touchpoints |
| Notes | A decline of 2+ points between consecutive surveys triggers proactive outreach. |

## 5. Operations KPIs

### O1 — Revenue Tracked

| Field | Value |
|-------|-------|
| Definition | Weekly revenue recorded and reconciled against bank deposits and invoices |
| Current Target | 100% reconciliation by Monday 09:00 for previous week |
| Tracking Method | Manual reconciliation logged in revenue snapshot report |
| Notes | Discrepancies > 5% flagged to Founder immediately. |

### O2 — Expenses Monitored

| Field | Value |
|-------|-------|
| Definition | Weekly expense review completed: all outflows categorized and compared to budget |
| Current Target | Reviewed and reported by Monday 09:00 alongside revenue |
| Tracking Method | Expense log + bank statement review |
| Notes | Unbudgeted expenses > $200 flagged to Founder for approval. |

### O3 — Reports Generated

| Field | Value |
|-------|-------|
| Definition | Operational reports delivered on schedule |
| Current Target | 4/wk (Monday morning report, Wednesday check-in, Friday summary, monthly deep-dive) |
| Tracking Method | Report delivery log |
| Notes | Each report must include: key metrics, variances from target, recommended actions. |
