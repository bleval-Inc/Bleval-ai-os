# Development Processes

## Development Flow
Jenson (requirements) → Forge (build) → Tester (QA) → Jenson (approve) → Deliver

## Release Process
1. Feature complete
2. Testing pass
3. QA sign-off
4. Jenson approval
5. Deploy

## Code Review Process
1. PR submitted
2. Tester reviews
3. Issues reported
4. Fixes applied
5. Final approval
